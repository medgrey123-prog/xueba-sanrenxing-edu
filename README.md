# xueba-sanrenxing-edu

“学霸三人行”教育判断与家长内容输出 Skill。

本 Skill 基于该账号按点赞排序的 Top 20 视频样本蒸馏，提炼教育判断框架、核心概念、可执行方法和内容输出模板。它适合用于家庭教育、学习习惯、学科规划、升学过渡等主题的分析与写作。

## 安装

将 `SKILL.md` 放入 Codex 的个人 Skills 目录：

```text
~/.codex/skills/xueba-sanrenxing-edu/SKILL.md
```

## 范围说明

这是基于 20 条高赞样本的有限蒸馏，不代表账号全部作品；涉及政策、研究、升学规则或具体课程书籍时，应独立核实来源。
